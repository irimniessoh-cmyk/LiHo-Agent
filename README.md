# حسابداری شخصی Liho

نسخهٔ فارسی موبایل با طراحی شیشه‌ای الهام‌گرفته از آرا.

## حساب‌ها
- در نصب تازه هیچ حسابی از پیش ساخته نمی‌شود.
- از دکمهٔ «＋ افزودن حساب» حساب دلخواه بسازید؛ نوع حساب، نام بانک، چهار رقم آخر کارت و موجودی اولیه اختیاری/قابل تنظیم‌اند.
- شمارهٔ کامل کارت را وارد نکنید.

## تاریخ و مبلغ
- نمایش تاریخ‌ها و انتخاب تاریخ در بخش‌های برنامه بر پایهٔ تقویم شمسی است.
- مبالغ هنگام تایپ و در نمایش‌ها با رقم فارسی و جداکنندهٔ هزارگان قالب‌بندی می‌شوند.

## ثبت پیامک
متن پیامک را خودتان کپی و در صفحهٔ ثبت پیامک بچسبانید؛ مبلغ تشخیص داده می‌شود و بعد دسته و حساب را انتخاب می‌کنید. وب‌اپ آیفون نمی‌تواند خودکار پیامک‌ها را بخواند.

## چک‌لیست کارهای روزانه
از گزینهٔ «کارها» در نوار پایین می‌توانید عنوان کار و یادداشت اختیاری بنویسید، آن را ویرایش یا حذف کنید و پس از انجام تیک بزنید. این بخش اعلان و ساعت ندارد و اطلاعات فقط روی همین دستگاه ذخیره می‌شود.

## لوگوهای بانک و انتخاب نوع حساب
فرم آزمایشی حساب اکنون با انتخاب نوع حساب، فیلدهای متناسب را نشان می‌دهد. لوگوهای ۳۶ بانک، مؤسسه و نئوبانک ایرانی به‌صورت محلی داخل برنامه قرار گرفته‌اند؛ برای نمایش لوگوی دقیق، نام بانک را از فهرست پیشنهادی انتخاب کنید. منبع دارایی‌ها: `mehrnet/IranianBanks`، مجوز MIT (متن مجوز در `IRANIANBANKS-LICENSE.txt`).

## انتشار به‌روزرسانی
این تغییرات فعلاً برای آزمون محلی‌اند و نباید تا پایان بررسی در GitHub جایگزین شوند. برای انتشار بعدی، `index.html` را در ریشهٔ مخزن GitHub جایگزین و Commit کنید. فایل‌های `manifest.webmanifest` و `liho-icon.png` که قبلاً در مخزن گذاشته شده‌اند، همان فایل‌های لازم برای نصب و آیکون هستند.
